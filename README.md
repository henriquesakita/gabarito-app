# GabaritoApp (modelo SARESP, letras manuscritas)
## Gerar o APK
A) Android Studio: File > Open nesta pasta, aguarde o sync, Build > Build APK(s). Saída: app/build/outputs/apk/debug/app-debug.apk
B) Sem instalar nada: suba esta pasta para um repositório no GitHub; na aba Actions rode "Build APK" e baixe o artefato "gabarito-apk".
## Instalar
Copie o app-debug.apk para o celular, abra e permita "instalar apps desconhecidos" para o app usado (Arquivos/Chrome).
